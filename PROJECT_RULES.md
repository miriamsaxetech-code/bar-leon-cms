# PROJECT RULES

## REUSE FIRST PRINCIPLE

- Search existing implementation before creating new code.
- Search .superpowers, NEXO, agents, docs, panel, tests and existing source code.
- Reuse before create.
- Extend before replace.
- Replace only with explicit justification.
- Identify duplicated functionality.
- Document existing functionality before rebuilding it.

**Default decision: REUSE.**
