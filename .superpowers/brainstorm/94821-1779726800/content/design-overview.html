Gestión de cariocas desde el panel NUEVO

Nueva pestaña "Carioca" en el admin. El dueño sube una imagen + texto corto. Activa/desactiva. La web la muestra automáticamente. Sin GitHub, sin commits, sin YAML.

Stack técnico — sin romper lo que funciona
📁

venue.json

Añadir campos: cariocas[], badge type en dishes. Sin cambiar arquitectura.

⚙️

Cloudflare Function

Nuevo endpoint /api/admin-save que escribe en GitHub API. Token en env var.

📱

admin-quick/

HTML/CSS/JS vanilla. Mobile-first. OAuth reutilizado. Sin dependencias.

🎨

carta.js + style.css

Spotlight section, pairing chips, badges, WhatsApp CTA, carioca block.
