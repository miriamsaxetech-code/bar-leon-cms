¿Quién toca el panel y desde dónde?

Esto define si el admin necesita ser mobile-first o puede ser desktop.

A

El dueño / encargado, desde el móvil

Necesita cambiar un precio o marcar "no hay callos hoy" en 10 segundos, entre servicio y servicio, sin sentarse al ordenador.

B

El dueño / encargado, en el ordenador

Tiene tiempo para actualizaciones semanales pero el flujo actual de Decap CMS es lento y confuso.

C

Alguien externo (agencia / técnico)

El restaurante pide cambios por WhatsApp y alguien los aplica. El objetivo es que el propio local pueda hacerlo solo.

D

Mixto — varios perfiles, varios dispositivos

A veces el dueño desde el móvil, a veces alguien técnico desde el ordenador. El sistema tiene que aguantar ambos.
