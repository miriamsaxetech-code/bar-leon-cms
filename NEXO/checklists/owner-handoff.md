# NEXO — Owner Handoff Checklist

> Completar en la sesión de entrega con el owner del local.
> Venue: ________________  Fecha: ________________  Owner: ________________

---

## Antes de la sesión

- [ ] Web en producción confirmada (smoke test OK)
- [ ] `delivery/owner-guide.md` impreso o enviado
- [ ] `delivery/cms-usage-guide.md` enviado por WhatsApp o email
- [ ] Owner tiene cuenta GitHub (crear si no tiene)
- [ ] Owner añadido como colaborador al repo con rol `Write`
- [ ] URL del CMS anotada y enviada: `{URL}/admin/`

---

## Durante la sesión — demostración

Mostrar al owner, en este orden:

- [ ] Abrir la web en el móvil del owner — confirmar que se ve bien
- [ ] Abrir `/admin/` en el móvil del owner
- [ ] Hacer login con GitHub (guiar si es la primera vez)
- [ ] Navegar a "Carta, Menú y Horarios (Español)"
- [ ] **Ejercicio 1:** cambiar el titular de inicio → guardar → verificar en la web
- [ ] **Ejercicio 2:** ocultar un plato (`disponible: No`) → verificar que desaparece
- [ ] **Ejercicio 3:** activar/desactivar el menú del día → verificar
- [ ] Revertir los cambios de demostración
- [ ] Mostrar cómo ver el historial en GitHub (para recuperación)

---

## Dudas frecuentes a cubrir

- [ ] "¿Cuánto tarda en aparecer el cambio?" → 30–60 segundos
- [ ] "¿Puedo hacerlo desde el móvil?" → Sí, el CMS funciona en móvil
- [ ] "¿Qué pasa si me equivoco?" → Se puede recuperar desde GitHub History
- [ ] "¿Puedo añadir platos nuevos?" → Sí, con el botón "Añadir" en la lista de carta
- [ ] "¿Cómo cambio los precios?" → Mismo proceso que editar cualquier campo

---

## Entregado al owner

- [ ] URL del sitio en producción
- [ ] URL del panel CMS
- [ ] Guía de uso (PDF / WhatsApp / email)
- [ ] Número de contacto del developer para urgencias
- [ ] Explicación del backup (GitHub History)

- [ ] Puede acceder al sitio web
- [ ] Puede acceder al panel CMS
- [ ] Hizo al menos un cambio y lo vio publicado
- [ ] Tiene la guía de uso guardada
- [ ] Sabe a quién llamar si algo falla
