# Bar León — Identity

## Core Rule

Bar León is a restaurant first.

Everything else supports the menu.

Priority order:

1. Carta restaurante
2. Carta barra
3. Bebidas
4. Bodega
5. Menú del día
6. Historia
7. Contacto

History builds trust.
Food generates revenue.

## Voice

Granada local.

Dry humour.

Friendly without performance.

Confident without arrogance.

No corporate language.
No luxury language.
No tourism clichés.

Mala follá ≠ rudeness.

Mala follá =
- brevity
- irony
- understatement
- character

## UX Rule

A hungry customer should reach food in under 2 taps.

If the user reads paragraphs before seeing dishes, the UX has failed.
